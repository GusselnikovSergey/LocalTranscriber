## 1. Что это за проект

Локальное настольное приложение (Windows, Python 3.14, Tkinter): аудио/видео → текст
(faster-whisper, CPU int8, PyAV вместо ffmpeg) и изображение/PDF → текст
(RapidOCR, русская модель `cyrillic_PP-OCRv5_rec_mobile`; PyMuPDF для текстового слоя).
Сеть нужна только для первой загрузки моделей, дальше офлайн.

## 4. Известные ограничения (не дефекты)

- Нет диаризации и потокового распознавания с микрофона — вне scope.
- Русская речь проверена только на синтетическом SAPI-голосе; нужен реальный файл заказчика.
- Модель `medium` замерена (68 с речи → 22,5 с); `large-v3` — только оценка (не скачивалась).
- `probe_duration` при добавлении файлов работает в главном потоке (для локальных файлов — мс).
- Кэш движков и `self.settings` читаются из worker-потока без блокировки (под GIL безопасно,
  но модель может подмениться посреди очереди).
