## 1. Цель

Дать пользователю одно настольное приложение под Windows, которое **полностью локально** превращает в текст:
- аудио- и видеозаписи (речь, преимущественно русская);
- изображения и PDF (сканы, фото документов, скриншоты).

Результат можно прочитать, отредактировать, скопировать и сохранить в нужном формате. Никакие файлы не покидают компьютер; сеть нужна только один раз — для скачивания моделей.

## 2. Границы задачи

### Входит в scope

- Приложение с графическим окном на Tkinter (Windows 10/11 x64, Python 3.14).
- Транскрибация речи из аудио/видео: `mp3, wav, m4a, aac, ogg, opus, flac, wma, mp4, mkv, avi, mov, webm`.
- OCR изображений: `png, jpg, jpeg, bmp, tif, tiff, webp`.
- PDF: извлечение готового текстового слоя; OCR только для страниц без текста.
- Очередь файлов (несколько файлов подряд), прогресс по каждому файлу, отмена текущего задания.
- Экспорт: `.txt` для всех типов; `.srt`, `.vtt`, `.json` с таймкодами — для аудио/видео.
- Настройки: модель Whisper (`small` / `medium` / `large-v3`), язык (`ru` / авто), число CPU-потоков, папка результатов, показывать ли таймкоды.
- Однократная загрузка моделей при первом запуске с индикатором прогресса и понятной ошибкой при отсутствии сети.
- Тесты (pytest), линтер (ruff), README с инструкцией запуска.

### Не входит в scope

- Сборка `.exe` (PyInstaller) и установщик — отдельная задача после приёмки MVP.
- Диаризация спикеров (кто говорил), субтитры по словам с точностью до слова.
- Потоковая транскрибация с микрофона в реальном времени.
- Перевод на другие языки, суммаризация, интеграция с облачными сервисами.
- Поддержка macOS/Linux, установка системных зависимостей (ffmpeg, tesseract).
- Редактор с подсветкой, поиск и замена по нескольким файлам.

## 4. Нефункциональные требования

- **Производительность**: на данной машине (36 ядер / 72 потока, CPU) `large-v3` int8 — не хуже 0.5× реального времени, `medium` int8 — не хуже 2× реального времени; OCR страницы A4 при 300 DPI — не более 3 с. Замеры фиксируются в отчёте разработки.
- **Память**: пиковый RSS при `large-v3` не более 8 ГБ; при `medium` — не более 5 ГБ.
- **Отзывчивость**: любая операция длиннее 200 мс выполняется вне главного потока Tkinter.
- **Надёжность**: ошибка отдельного файла не останавливает очередь; приложение не падает на битых/неподдерживаемых файлах; корректное завершение по закрытию окна (задание отменяется).
- **Совместимость**: Windows 10/11 x64, Python 3.14 (CPython), зависимости закреплены в `requirements.txt`; внешние бинарники (ffmpeg, tesseract) не требуются.
- **Безопасность и приватность**: медиа и документы не покидают машину; телеметрии нет; сеть — только загрузка моделей с официальных репозиториев.
- **Наблюдаемость**: структурированный лог с уровнями, время на файл, выбранная модель/движок, длительность и число сегментов.

## 5. Допущения

- Машина пользователя имеет доступ в интернет для однократной загрузки моделей (проверено: huggingface.co и modelscope.cn доступны).
- Объём моделей: `medium` ≈ 0.8–1.5 ГБ, `large-v3` ≈ 3 ГБ, OCR `cyrillic` ≈ 20 МБ — место на диске есть.
- Пользователь работает с русской речью средней разборчивости; для шумных записей качество ограничено моделью (в README — рекомендация `large-v3`).
- Tkinter доступен в установке Python 3.14 (проверяется при старте, иначе — понятное сообщение).
- Записи длиннее 2 часов обрабатываются, но пользователь предупреждён о времени (оценка выводится в интерфейсе).

## 8. Тестовая стратегия

- **Модульные тесты** (без моделей): сборка абзацев из сегментов, форматирование SRT/VTT/JSON, определения типа файла, склейка страниц PDF, загрузка/сохранение настроек, экранирование путей, оценка времени по длительности.
- **Интеграционные тесты** (помечены `slow`, запускаются вручную/по флагу): короткий wav (2–5 с) через Whisper-`small`, изображение с русским текстом через OCR, PDF с текстовым слоем через PyMuPDF.
- **Регрессия**: `pytest -q` на каждый DEV-отчёт; `ruff check .`; импорт пакета.
- **Ручные проверки**: 
  1. Перетащить `.mp3` (1 мин) → текст, копирование, сохранение `.txt`/`.srt`.
  2. Обработать `.mp4`, `.pdf` (скан) и `.jpg` подряд в одной очереди.
  3. Отмена на середине длинного файла; закрытие окна во время обработки.
  4. Отключить сеть после загрузки моделей → обработка работает.
  5. Перезапуск → настройки сохранены.
- **Граничные случаи**: пустой файл; файл без звуковой дорожки; повреждённый PDF; PDF на 100+ страниц (прогресс по страницам); изображение без текста; имя файла с кириллицей и пробелами; очень длинный файл (оценка времени).
