## Требования

- FR-12, FR-14, FR-15.
- `models_setup.py`: проверка наличия модели Whisper (`config.json` + `model.bin` в каталоге модели) и моделей OCR; загрузка с прогрессом/статусом; понятные ошибки при отсутствии сети; кэш в `%LOCALAPPDATA%\LocalTranscriber\models`.

- `testdata/`: короткий синтетический сэмпл для тестов (генерируется скриптом, без внешних файлов).
- Проверка офлайн: обработка после отключения сети.
