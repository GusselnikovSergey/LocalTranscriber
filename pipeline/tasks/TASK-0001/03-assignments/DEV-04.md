## Требования

- FR-01, FR-05, FR-08, FR-09, FR-10, FR-11, FR-13.
- Окно: список файлов со статусами, «Добавить файлы», drag&drop (опционально `tkinterdnd2`), «Обработать», «Отмена», «Очистить».
- Обработка в отдельном потоке, события через `queue.Queue`, опрос из UI через `after(100)`, прогресс-бар и текст статуса.
- Редактор результата (Text), «Копировать», «Сохранить как…» (txt/srt/vtt/json по типу результата), «Открыть папку», таймкоды по настройке.
- Окно настроек: модель, язык, потоки, папка результатов, таймкоды; сохранение в settings.json.
- Ошибка одного файла не останавливает очередь; ошибки — короткое сообщение + лог.
- Тесты: очередь (успех, ошибка, отмена) на фейковом движке без моделей.
