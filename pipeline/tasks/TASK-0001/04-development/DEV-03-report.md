# Отчёт DEV-03: OCR (RapidOCR, русская модель) и PDF (PyMuPDF)

## Что сделано

- `engines/ocr_engine.py`:
  - ленивая инициализация `RapidOCR` (`onnxruntime`, CPU) с русской моделью
    `cyrillic_PP-OCRv5_rec_mobile`, кэш моделей в `%LOCALAPPDATA%\LocalTranscriber\models\ocr`;
  - `Global.use_cls=False`, `Rec.ocr_version=PP-OCRv5`, `Rec.model_type=mobile` (подобрано по конфигу RapidOCR 3.10);
  - построчная сортировка блоков: кластеризация по центру строки с допуском от медианной высоты, внутри строки — слева направо (`sort_text_lines`);
  - поддержка пути, PIL-изображения и numpy-массива, EXIF-ориентация, понятная ошибка при недоступности моделей.
- `pdf.py`: постраничный разбор — текстовый слой `page.get_text("text")` берётся, если после удаления пробелов ≥ 40 символов; иначе страница рендерится в 300 DPI (`csRGB`, без альфы) и распознаётся OCR; результат склеивается с маркерами `--- стр. N ---`; отмена по страницам, прогресс по страницам; `PdfProcessor` как адаптер под общий интерфейс движка.
- Тесты: `tests/test_pdf.py` (текстовый PDF, сканированный PDF с фейковым OCR, PDF с паролем, отмена), `tests/test_ocr_engine.py` (сортировка строк, фабрика движка, `slow`-тест русского OCR).

## Изменённые файлы

`src/localtranscriber/engines/ocr_engine.py`, `src/localtranscriber/pdf.py`,
`tests/test_ocr_engine.py`, `tests/test_pdf.py`.

## Как проверено

```text
python -m pytest -q tests/test_pdf.py tests/test_ocr_engine.py   → passed
```

Сквозная проверка на сгенерированных данных (`scripts/make_testdata.py`):

```text
[OCR] первый запуск (с загрузкой модели) 2.9 с, повторный 0.87 с
Локальная транскрибация текста
Проверка распознавания: строка 2
Москва, 2026 год

[PDF digital] 0.1 с, OCR-страниц=0 → текстовый слой извлечён точно
[PDF scanned] 4.0 с, OCR-страниц=1 → текст распознан верно
```

## Отклонения от задания

- Вместо Tesseract используется RapidOCR: в системе нет tesseract, а RapidOCR ставится колесом и работает на уже установленном onnxruntime.
- Порог «страница считается текстовой» — 40 непробельных символов; вынесен в параметр `min_chars`.

## Риски

- Первый OCR-запуск требует сети (≈20 МБ моделей); далее — офлайн.
- Качество на плохих сканах ограничено; в README описаны рекомендации (300 DPI, ровный скан).
