# Отчёт DEV-04: GUI (Tkinter), очередь заданий, прогресс, отмена, экспорт

## Что сделано

- `jobs.py`: `JobQueue` — последовательная обработка в фоновом потоке, события через `queue.Queue`
  (`job_status`, `progress`, `job_done`, `job_error`, `queue_done`), токен отмены, изоляция ошибок
  (сбой одного файла не останавливает очередь), очистка только вне работы.
- `ui/main_window.py`:
  - дерево файлов (имя, тип, длительность, статус), редактор результата, прогресс-бар, статусная строка;
  - кнопки «Добавить файлы», «Обработать», «Отмена», «Очистить», «Настройки», «Открыть папку результатов»,
    «Копировать», «Сохранить как…»;
  - меню и горячие клавиши Ctrl+O / Ctrl+S / F5;
  - drag&drop через `tkinterdnd2` при наличии, аккуратный откат на кнопку;
  - обработка в отдельном потоке, опрос событий через `after(100)`, отмена по кнопке и при закрытии окна;
  - автопосохранение каждого результата в `<папка результатов>\<имя>.txt` (с уникальным суффиксом);
  - сохранение в `.txt` (все типы) и `.srt`/`.vtt`/`.json` (речь), понятные сообщения об ошибках;
  - настройки в диалоге с валидацией и сохранением в `settings.json`, сброс кэша движков при изменении.
- `ui/widgets.py`: `TextPanel`, `SettingsDialog`.
- `app.py`, `__main__.py`: точка входа, DPI-awareness, логирование, системные сертификаты.
- Тесты: `tests/test_jobs.py` (успех, ошибка, отмена, запрет очистки во время работы, диапазон прогресса).

## Изменённые файлы

`src/localtranscriber/jobs.py`, `src/localtranscriber/app.py`, `src/localtranscriber/__main__.py`,
`src/localtranscriber/ui/{__init__,main_window,widgets}.py`, `tests/test_jobs.py`.

## Как проверено

```text
python -m pytest -q tests/test_jobs.py   → passed
```

Проверка GUI без ручного участия (`scripts/gui_smoke.py`): окно создаётся, в очередь добавляются
`sample.png`, `digital.pdf`, `scanned.pdf`, запускается обработка, все три файла завершаются со статусом
«Готово», результат выводится в редактор, `.txt` сохраняются автоматически. Результат зафиксирован в DEV-05.

## Отклонения от задания

- Автосохранение `.txt` включено для каждого готового файла (требование FR-10 о пакетном сохранении);
  при сохранении через диалог можно выбрать формат.
- Для речи в редакторе с таймкодами показываются строки `[мм:сс]`, а `.srt`/`.vtt`/`.json` строятся из
  исходных сегментов (правки редактора влияют только на `.txt`) — поведение описано в README.

## Риски

- При очень длинных записях редактор держит весь текст в памяти — для часовых файлов это десятки килобайт, приемлемо.
- Tkinter не поддерживает drag&drop без `tkinterdnd2`; библиотека включена в зависимости, но приложение работает и без неё.
