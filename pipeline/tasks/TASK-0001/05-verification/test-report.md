## 4. Найденные дефекты

### D-01 — `run.ps1` не запускается в Windows PowerShell 5.1 (major)

- **Серьёзность**: major (FR-15; основная команда запуска из README не работает).
- **Файл**: `run.ps1` (UTF-8 **без BOM**, LF).
- **Воспроизведение**:
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1
  ```
- **Ожидаемо**: скрипт создаёт/использует `.venv`, ставит зависимости (маркер `.deps-installed`), запускает `python -m localtranscriber`.
- **Фактически**: ошибка парсера:
  ```text
  At ...\run.ps1:22 char:39
  + $env:PYTHONPATH = Join-Path $root "src"
  The string is missing the terminator: ".
  At ...\run.ps1:14 char:31
  Missing closing '}' in statement block or type definition.
  ```
  Код возврата 1, приложение не запускается, `.venv\.deps-installed` не создаётся.
- **Причина (проверено)**: Windows PowerShell 5.1 читает `.ps1` без BOM как ANSI; кириллические комментарии/строки ломают разбор. Копия того же файла с UTF-8 BOM парсится без ошибок (`Parser::ParseFile` → `parse ok`). В системе нет `pwsh`, поэтому обойти это иначе нельзя.
- **Рекомендация**: сохранить `run.ps1` в UTF-8 **с BOM** (или UTF-16 LE с BOM), либо писать комментарии/строки только латиницей; добавить проверку запуска скрипта в CI/приёмку.

### D-02 — Нет модели и нет сети: пользователь видит «Непредвиденная ошибка» вместо инструкции (major)

- **Серьёзность**: major (FR-12, Must: «при отсутствии сети — понятное сообщение с инструкцией»).
- **Файл**: `src/localtranscriber/models_setup.py:54-64` (`repo_files`): вызов `_request(...)` находится **вне** `try/except`, поэтому `requests.exceptions.ConnectionError` не превращается в `ModelUnavailableError`.
- **Воспроизведение**: запретить `socket.connect`/`socket.create_connection`, вызвать `ensure_whisper_model("large-v3")` (модели нет) — напрямую или через `JobQueue`, как это делает GUI при добавлении аудио.
- **Ожидаемо**: `ModelUnavailableError` с текстом вида «Не удалось получить список файлов модели. Проверьте интернет-соединение…»; в интерфейсе — короткое понятное сообщение.
- **Фактически**:
  ```text
  status: error
  message: Непредвиденная ошибка: HTTPSConnectionPool(host='huggingface.co', port=443):
  Max retries exceeded with url: /api/models/Systran/faster-whisper-large-v3?blobs=true
  (Caused by NewConnectionError(...))
  ```
  Плюс полный traceback в лог (для непредвиденных ошибок это штатно, но здесь ошибка ожидаемая).
- **Рекомендация**: обернуть `_request` (и `response.json()`) в `try/except requests.RequestException` → `ModelUnavailableError` с инструкцией; тест «нет сети + нет модели».

### D-03 — Отмена распознавания длинного аудио превышает 3 с (major)

- **Серьёзность**: major (FR-05, Must: «отмена завершает задание не позднее 3 с»).
- **Файлы**: `engines/whisper_engine.py:45-59` (проверка отмены только между сегментами), `audio.py` (проверка по кадрам — здесь ок).
- **Воспроизведение**: `speech_en_long.wav` (68,1 с, 12 сегментов, самый длинный 12,34 с), `CancelToken.cancel()` в разные моменты; замер от `cancel()` до `CancelledError`.
- **Ожидаемо**: ≤3 с.

### 7.4. Найденные проблемы
